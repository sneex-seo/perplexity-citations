# perplexity-citations

Показує, які сайти Perplexity бере за джерела, коли відповідає на ваші промпти.

Даєте список запитів, скрипт проганяє їх через Perplexity API і для кожної відповіді зберігає:
- усі сторінки, які знайшов пошук;
- ті з них, на які відповідь справді посилається, і в якому порядку;
- зведення по доменах: хто цитується найчастіше і в скількох відповідях.

Для чого це:
- **GEO.** Видно, з яких сайтів AI збирає відповідь у вашій ніші і чи є серед них ваш.
- **Лінкбілдинг і PR.** Сайти, які AI цитує найчастіше, - перші кандидати на згадку чи публікацію.
- **Контент.** Запити, де вас немає серед джерел, показують, яких сторінок не вистачає.

Приклад звіту на 30 запитів: https://oleksiimatuznyi.com/lab/perplexity-citations/

## Запуск

Потрібен Python 3.10+ і ключ Perplexity API. Ключ створюється в консолі https://console.perplexity.ai/project/keys, оплата за фактом використання.

```bash
git clone https://github.com/sneex-seo/perplexity-citations.git
cd perplexity-citations
pip install -r requirements.txt
cp .env.example .env          # Windows: copy .env.example .env
python citations.py prompts.example.txt
```

Ключ впишіть у `.env` у рядок `PERPLEXITY_API_KEY=`. Файл `.env` не потрапляє в git.

Свої промпти покладіть у txt, по одному на рядок, або в першу колонку xlsx чи csv.

## Параметри

```bash
python citations.py prompts.txt --domain example.com.ua   # де ваш сайт цитують, а де ні
python citations.py prompts.txt --effort low              # глибший пошук: кілька запитів, більше джерел
python citations.py prompts.txt --country ""              # пошук без прив'язки до України
python citations.py prompts.txt --limit 5                 # лише перші 5 промптів, для перевірки
python citations.py --report-only                         # перебудувати звіти з журналу без запитів
```

| Параметр | Що робить |
|---|---|
| `--domain` | Ваш домен. У звіті з'являється статус для кожного запиту: процитовано, знайдено, але не процитовано, або немає серед джерел. Піддомени рахуються як ваші. |
| `--effort` | Режим Perplexity Agent API: `fast` (за замовчуванням, один пошук), `low`, `medium`, `high`. Чим глибше, тим більше джерел, довше і дорожче. |
| `--country` | Код країни, з якої шукати. За замовчуванням `UA`, порожній рядок прибирає прив'язку. |
| `--domain-filter` | Шукати лише на цих доменах, через кому. Домен із мінусом виключається. |
| `--recency` | Лише свіжі джерела: `day`, `week`, `month`, `year`. |
| `--exclude-tld` | Не показувати у звітах джерела з цих доменних зон, через кому, наприклад `ru,by`. Звіт пише, скільки джерел приховано, журнал лишається повним. |
| `--out-dir` | Куди писати журнал і звіти, за замовчуванням `results`. |
| `--fresh` | Прогнати промпти заново, а не брати відповіді з журналу. |

## Що виходить

У папці `results`:
- `report.html` - звіт: підсумок, таблиця доменів, кожна відповідь із пронумерованими джерелами;
- `citations_YYYY-MM-DD.xlsx` - аркуші «Відповіді», «Джерела», «Домени», а з `--domain` ще «Ваш домен»;
- `journal.jsonl` - журнал. Він пишеться після кожного промпту, тому перерваний прогін можна запустити знову: готові промпти не повторюються і не оплачуються вдруге.

Процитованими вважаються джерела, на які відповідь посилається маркерами `[1]` або `[web:1]`. Решта знайдених сторінок теж є у звіті з позначкою «не процитовано».

## Скільки коштує

На прикладі з 30 запитів у листопаді 2026 року режим `fast` коштував близько $0.002 за запит, `low` - близько $0.004. Скрипт показує вартість кожного запиту і всього запуску за даними самого API. Актуальні ціни: https://docs.perplexity.ai/getting-started/pricing

## Обмеження

- Скрипт працює через Perplexity Agent API. Відповіді в API і в застосунку perplexity.ai можуть відрізнятися: там інші моделі, персоналізація та історія розмови.
- Відповіді змінюються від запуску до запуску. Для висновків краще брати кілька десятків запитів, а не один.
- Прив'язка до країни м'яка: вона піднімає частку локальних джерел, але не прибирає інші.
- Код надається «як є». Питання й помилки можна писати в Issues, але без гарантії термінів.
